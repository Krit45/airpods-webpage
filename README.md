# 🎧 AirPods Website

A modern and responsive landing page for **AirPods**, built using **HTML**, **CSS**, and **JavaScript**. The project focuses on creating a clean user interface with smooth interactions, responsive layouts, and an engaging user experience.

---

## ✨ Features

- 🎨 Modern and clean user interface
- 📱 Fully responsive design
- ⚡ Smooth scrolling experience
- 🖱 Interactive buttons and hover effects
- 🎯 Clean section layouts
- 📦 Organized project structure
- 🌐 Cross-browser compatible
- ⚙ Built with pure HTML, CSS, and JavaScript
- 🚀 Lightweight and fast loading

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 💻 Getting Started

Clone the repository

```bash
git clone https://github.com/krit45/airpods-website.git
```

Navigate to the project folder

```bash
cd airpods-website
```

Open `index.html` in your browser.

No installation or dependencies are required.
